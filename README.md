# SauceDemo Manual Testing

## About This Project
This project is a Manual Software Testing project using the SauceDemo website. The purpose is to practice software testing skills, create test cases, execute test scenarios, and record actual test results.

**Website Under Test:** [SauceDemo](https://www.saucedemo.com/)

## Objectives
- Practice manual software testing.
- Create and execute test cases.
- Verify application functionality.
- Compare actual results with expected results.
- Capture screenshots as test evidence.

## Testing Scope

The current testing scope includes:

### 1. Login
- Login with valid credentials.
- Login with invalid password.
- Login with invalid username.
- Login with empty username and password.
- Login with empty username.
- Login with empty password.

### 2. Product Page
- Verify the product list.
- Verify product names, images, descriptions, and prices.
- Verify that all 6 products are displayed.

### 3. Shopping Cart
- Add a product to the shopping cart.
- Verify that the product displayed in the cart matches the selected product.
